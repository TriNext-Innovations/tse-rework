Local Development

Prerequisites

  • Node 20+, pnpm 9+
  • Docker + Docker Compose

Setup

# 1. Install dependencies
pnpm install

# 2. Configure env files
cp apps/backend/.env.example apps/backend/.env
cp apps/web/.env.example     apps/web/.env.local

# 3. Start Postgres + Redis
docker-compose up -d

# 4. Run Medusa migrations
pnpm --filter @tse/backend migrate

# 5. Seed the database (559 products, SA region, categories)
pnpm tsx scripts/seed.ts

# 6. Start all apps
pnpm dev

Deployment

Push to main → .github/workflows/deploy.yml → SSH into Vultr VM → git pull + docker compose up --build -d → health check → rollback on failure.

Full runbook: docs/PROD-DEPLOY.html
