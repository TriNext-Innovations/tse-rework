Key Patterns

  • Server Components by default — fetch directly from Medusa SDK server-side; no client-side waterfalls
  • Client Components only for interactivity — cart drawer, quantity selectors, wizard steps
  • ISR — revalidate: 3600 + on-demand via Medusa webhook calls to /api/revalidate
  • Optimistic updates — cart actions use React useOptimistic

Custom Modules

Compatibility — compatibility table: printer_brand → printer_model → cartridge_compatibility → product. Wizard queries via GET /store/compatibility.

B2B — Extends Medusa customer groups with pricing_tier (standard / reseller / wholesale). Custom price list auto-applied at checkout based on authenticated customer's group.

Courier — Wraps Courier Guy and Aramex APIs. Calculates rates based on order weight, destination province, and 12:00 SAST cutoff for next-day JHB/PTA delivery.

Database Schema (custom tables)

All standard Medusa tables are inherited. Custom additions:

-- Cartridge compatibility
CREATE TABLE compatibility (
  id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  brand       TEXT NOT NULL,
  model       TEXT NOT NULL,
  sku         TEXT NOT NULL,
  created_at  TIMESTAMPTZ DEFAULT NOW()
);

-- B2B pricing tiers (extends Medusa customer_group)
ALTER TABLE customer_group ADD COLUMN pricing_tier TEXT DEFAULT 'standard';

-- Quote requests
CREATE TABLE quote_request (
  id           UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  customer_id  TEXT NOT NULL,
  items        JSONB NOT NULL,         -- [{sku, qty}]
  note         TEXT,
  status       TEXT DEFAULT 'pending', -- pending | quoted | accepted | rejected
  created_at   TIMESTAMPTZ DEFAULT NOW()
);

Full compatibility schema (with indexes) in data-model.html.

Deploy flow: push to main → GitHub Actions → SSH into VM → git pull && docker compose up --build -d → health check → rollback on failure.

SSL: Let's Encrypt SAN cert (certbot standalone). nginx terminates TLS, forwards to containers.

Cloudflare

  • DNS: A records dev, api.dev → Vultr main VM public IP (Proxied)
  • SSL/TLS: Full (Strict)
  • Page rule: bypass cache on api.dev.tse-cartridges.co.za/*
  • DDoS protection active on all proxied records

Cloudflare R2 (file storage)

  • Bucket: tse-product-images (public-read)
  • Free tier: 10 GB storage + 1 M operations/month
  • Zero egress fees when served through Cloudflare CDN
  • Connected to Medusa via @medusajs/file-s3 (R2 is S3-compatible)

Vultr JHB n8n VM

  • Separate 1 GB VM — isolates automation from the main server
  • Docker Compose with single n8n service
  • Same GitHub Actions SSH deploy pattern
