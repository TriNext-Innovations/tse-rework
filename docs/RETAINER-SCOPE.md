# TSE Online — Monthly Retainer Scope

## Overview

The monthly retainer keeps TSE Online's platform running, growing, and
marketing itself. It covers three pillars: **Infrastructure**, **Marketing Automation**,
and **Retained Development**.

---

### What we do

- Monitor uptime and VM resource usage (CPU, RAM, disk) daily

- Manage database backups (daily pg_dump to Vultr Object Storage)
- Tail Docker Compose logs for errors and container restarts
- Keep all API integrations (PayFast, Ozow, Meta) functional as their APIs evolve

## Pillar 2 — Marketing Automation (~R3,500/month)

### Instagram & Facebook Bot

The automation engine (n8n + Claude API + Meta Graph API) runs on auto-pilot.
Each month we:

- Review and optimise the Claude caption-generation prompt based on engagement data
- Update the posting schedule seasonally (e.g. more posts before back-to-school)
- Monitor Meta API token refresh (long-lived tokens expire every 60 days)
- Review and curate the image composition template (branding overlays)
- Report on top-performing posts: reach, impressions, link clicks

**Posting cadence (default):**
- New products: post within 2 hours of being added
- Restocked items: post within 4 hours of stock going live
- Weekly "tip" post: e.g. "How to get more pages from your cartridge" — generated by Claude, reviewed by us before publishing
- Monthly promotion: client provides the deal details, we create the post

### Variable costs (passed through at cost)

| Service | Purpose | Est. monthly cost |
|---|---|---|
| Anthropic API (Claude captions) | Caption generation for every social post | ~R30–80 |

Volume depends on posting cadence. At default schedule (~30 posts/month using Claude Haiku) cost is under R50.

### Monthly Report

Delivered by the 5th of each month covering:
- Orders and revenue (pulled from Medusa)
- Top-selling products and low-stock alerts
- Website traffic (Cloudflare Web Analytics + Google Analytics)
- Instagram/Facebook: follower growth, post reach, engagement rate
- Recommendations for next month

## Pillar 3 — Retained Development (~R2,500/month)

**5–8 hours of development time per month**, used for:

- New feature requests (banners, promotional pricing, new product categories)
- Seasonal homepage updates (e.g. Year-End sale, Budget Day specials)
- Bulk product or pricing updates
- Bug fixes outside the 30-day warranty period
- Minor UX improvements based on analytics data
- n8n workflow adjustments

Hours in excess of 8 are billed at **R450/hour** (agreed in advance).

- **Monthly review:** 30-min Google Meet on first Monday of each month
- **Emergency support** (site down, payment failure): respond within 2 hours during business hours

## What the Client Owns

At all times, TSE Online has full ownership of:
- The GitHub repository (we invite them as an owner)
- The Vultr account and both VMs (they are the account holder)
- The Vultr Object Storage bucket
- The domain and DNS (their Cloudflare account)
- All Meta Business assets (Facebook Page, Instagram account)

If the retainer is cancelled, we hand over all credentials and documentation
within 5 business days. The platform continues running — nothing breaks.
