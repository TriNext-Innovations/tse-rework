Brand Tokens

CSS custom properties in HSL triplet format (H S% L% — no hsl() wrapper). This format is required for Tailwind opacity modifiers (bg-brand-primary/50) to work correctly.

shadcn Semantic Token Mapping

shadcn components use --background, --primary, --border, etc. These are mapped onto brand tokens in the shadcn Variable Mapping block in globals.css. Never set colour values in the mapping block — change them only in Brand Tokens.

--foreground--brand-text

How to Rebrand

  1. Open apps/web/src/app/globals.css
  2. Edit the HSL values in the /* ─── BRAND TOKENS ─── */ block
  3. Update this doc's table to match

All components, shadcn UI, and Tailwind utilities update automatically.
