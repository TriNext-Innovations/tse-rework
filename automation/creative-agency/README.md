# TSE creative agency

An automated creative department for TSE's Facebook and Instagram: it plans a
weekly campaign, writes and judges concepts, art-directs and generates
imagery, sets real TSE type and logo over it, inspects the finished file, and
publishes two ads a day (08:00 and 20:00 SAST) — keeping seven days of
approved work queued.

**Status:** built and tested locally against mocks, and inside a real n8n
2.37.9. Not deployed. Live publishing is off by three independent switches.
See [docs/TEST-REPORT.md](docs/TEST-REPORT.md) for exactly what has and
hasn't touched a live service.

```
 n8n (schedules, retries, Discord)            agency service (Python, Postgres)
 ───────────────────────────────              ─────────────────────────────────────────────
 1 Planning      daily 05:30  ── /v1/plan ──▶  Strategist ─▶ 14 assignments / week
 2 Production    every 20 min ── /v1/cycle ─▶  Copywriter ─▶ Creative director ─▶ copy QC
                                               Art director ─▶ fal.ai ─▶ renderer ─▶ QC (rules + vision)
 5 Publishing    every 15 min ── /v1/publish ▶ due slot ─▶ preflight ─▶ Meta Graph (FB + IG), once
 6 Performance   daily/Monday ── /v1/metrics, /v1/report/weekly ─▶ guidance for next week's plan
 7 Monitoring    hourly/daily ── /v1/recover, /v1/alerts/claim, /v1/health
```

n8n owns *when*; the service owns *what* and *whether*. Every decision that
needs state, locking or money control lives in the service, where it is tested.

## Layout

| Path | What |
|------|------|
| `agency/` | the service: pipeline stages, renderer, QC, Meta/fal/Claude clients, HTTP API, CLI |
| `agency/prompts/` | versioned agent instructions (strategist, copywriter, director, art director, QC, analyst) |
| `brand/brand_book.md` | positioning, voice, audience, visual standard |
| `brand/verified_facts.json` | **the only claims the agency may make**, each with source URL and evidence text |
| `brand/logo/`, `brand/fonts/` | official logo (rasterised from `apps/web/public/brand/logo-v2*.svg`), Fraunces + Inter (OFL) |
| `migrations/` | Postgres schema |
| `n8n/` | importable workflows (generated by `scripts/build_workflows.py`) |
| `tests/` | 72 tests: unit, pipeline, HTTP, fake fal + Graph servers |
| `docs/` | operations, decisions, test report |

## Quick start (local, offline, free)

```sh
uv venv -p 3.12 .venv && uv pip install -p .venv -e ".[test]"
docker run -d --name agency-test-pg -e POSTGRES_USER=agency -e POSTGRES_PASSWORD=agency \
  -e POSTGRES_DB=agency -p 127.0.0.1:55432:5432 postgres:16-alpine
.venv/bin/python -m pytest                     # full suite
AGENCY_DEMO_RESET=yes DATABASE_URL=postgresql://agency:agency@127.0.0.1:55432/agency \
  .venv/bin/python -m agency demo --slots 4    # end-to-end dry run → var/demo/index.html
```
